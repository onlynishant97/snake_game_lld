# Snake Game

## Problem Statement

Design and implement a Snake Game in Java using object-oriented design principles.

The game consists of a snake moving on a rectangular board. The snake can move in four directions: up, down, left, and right. The objective is to eat food, grow in length, and achieve the highest possible score without colliding with its own body.

Whenever the snake consumes food, its length increases and the score is updated. New food is generated at an unoccupied position on the board.

The game ends when the snake collides with itself. If the snake occupies every cell on the board, the player wins.

The board boundary behavior should be configurable so that different boundary-handling strategies can be supported.

The implementation should focus on clean object-oriented design, separation of responsibilities, and extensibility.
